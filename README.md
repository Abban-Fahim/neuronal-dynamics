My solutions to the accompanying exercises of the book Neuronal Dynamics, which has generously been made freely accessible by their authors at [EPFL LCN](https://www.epfl.ch/labs/lcn/). The online version of the textbook can be found [here](https://neuronaldynamics.epfl.ch/), and the exercises [here](https://neuronaldynamics-exercises.readthedocs.io/en/latest/), where you can also find instruction to install the provided Python library on all platforms ([here](https://neuronaldynamics-exercises.readthedocs.io/en/latest/setup.html)), which you need to follow to run my code.
